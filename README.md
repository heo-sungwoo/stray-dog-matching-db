## 🗂️ DB 설계

### ERD 구조 (팀 공동 설계)
```
입양자 ──────── 매칭 ──────── 유기견
  │                              │
  └── 설문결과              견종정보
  └── 가구정보              건강상태
  └── 주거환경              활동량

용품커머스 (본인 설계)
  └── 카테고리
  └── 재고
  └── 주문
```

### 본인 담당 테이블 (10+개)
- 입양자 마스터 테이블
- 설문 응답 테이블
- 매칭 결과 테이블
- 유기견 케어 용품 카테고리·재고·주문 테이블 (커머스 DB)
- 기타 분석용 집계 테이블

## 🔍 45개 분석 쿼리

> 단순 조회가 아닌, **비즈니스 인사이트 도출 → 정책 제안**까지 연결

### Category 01 — 매칭 정확도·추천 신뢰성
```sql
-- 매칭 점수 Top10 유기견의 실제 입양 전환율
SELECT breed, matching_score, contract_rate
FROM matching_result
WHERE rank <= 10
ORDER BY matching_score DESC;
```
- 매칭 점수 Top10 견종 → **70~100% 계약 전환율** 확인
- 견종별 매칭 성공률 분석
- 추천 알고리즘 효용성 검증 (Baseline 비교)

### Category 02 — 파양 위험 탐지
```sql
-- 고위험 조합: 1인가구 × 활동량 최상위
SELECT adopter_id, household_size, dog_activity_level
FROM adopter_profile
WHERE household_size = 1
  AND dog_activity_level = 5;
-- 결과: 89건 / 중·대형견 비중 66%
```
- 대형견 × 원룸 거주자 → **장기 입양 유지율 2.11%**
- 1인가구 × 활동량 5 → 89건 고위험 케이스 식별
- 고령견 × 반려경험 없음 케이스 탐지

## 📊 핵심 인사이트 + 정책 제안

### ✅ 매칭 모델 유효성 입증
| 지표 | 결과 |
|------|------|
| Top10 추천 견종 계약 전환율 | **70~100%** |
| 매칭 기반 vs 무작위 추천 | 매칭 기반이 유의미하게 높음 |

### ⚠️ 고위험 조합 01 — 1인가구 × 활동량 5
- 식별 건수: **89건** / 중·대형견 비중 66%
- **정책 제안**: 추천 알고리즘에 가구원수 × 활동량 가드레일 도입

### ⚠️ 고위험 조합 02 — 대형견 × 원룸
- 장기 입양 유지 비율: **2.11%**
- **정책 제안**: 주거환경 불일치 매칭 사전 차단

### ⚠️ 고난이도 케어 — 고령견 × 초보 입양자
- 대상: 120개월↑ 견 × 반려경험 없음
- **정책 제안**: 추천 시 케어 체크리스트·상담 유도 가드레일
